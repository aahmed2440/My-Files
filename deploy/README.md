# CryptoSphere deployment roots

These directories contain sealed, dependency-complete CryptoSphere deployment archives. No credentials, identity-proxy secrets, or real fleet/enterprise target URLs are stored here. Runtime secrets and allowlists must be injected by the hosting platform.

- `cryptosphere-owner`: Owner / Principal Admin Console V1.4.1, read-only exact-allowlist diagnostics.
- `cryptosphere-core`: Core V0.90.1 integrated analytical engine, advisory-only and human-governed.
